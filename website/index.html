How we keep reviews fast.

The compact review path sends bounded context and asks for a short, severity-only reply. Recent matching results are cached, duplicate requests share work, and a persistent local service reuses connections. Reviews run in the background so provider waits don’t block the command hook.

Connect a model in VS Code.

  1. Open LLM settings in Distill, or run Distill: Configure LLM Router.
  2. Choose your provider and model. Add an API key for a cloud provider, or set your local server endpoint.
  3. Enable routing and select Apply settings. Model advice appears alongside the command assessment.

When enabled, your selected provider receives the command and bounded analysis context. Sharing inspected script excerpts is a separate opt-in setting. API keys are stored in VS Code’s encrypted SecretStorage. Static findings and analysis gaps remain visible alongside model advice.

KNOW WHERE THE EDGES ARE

Local by design.
Explicit about limits.

Read coverage and limits →
◎

Local static analysis

The Rust analyzer runs on your machine. Optional model advice uses your selected cloud provider or local model server when you enable it.

◒

Unknown means unknown

Static analysis is bounded. Recognizing a tool does not prove arbitrary application code safe.

⌁

Privacy has boundaries, too

Editor command history stays in memory. Saved API keys use encrypted SecretStorage. Standalone CLI users can opt into a separate session ledger.

⊞

Containment is opt-in

analyze does not execute commands. run uses native containment; installing hooks does not enable it automatically.

07 / BEFORE YOU BEGINA FEW USEFUL ANSWERS

A FEW USEFUL ANSWERS

Before you begin.

Does Distill execute the command to analyze it?+

No. analyze and hook assessment inspect commands without executing them. The separate run subcommand is an opt-in execution gate.

Is a “safe” rating a guarantee?+

No. It describes modeled impact within the supported static semantics. Coverage, source dependencies, shell context, and host permissions still matter. Incomplete coverage can require review even when the modeled impact is safe.

Does installing the hooks sandbox my agent?+

No. Hooks are analysis adapters. Execution goes through native containment only when explicitly routed through distill run. macOS uses Seatbelt; supported Linux kernels use Landlock and seccomp.

Which editor environments are supported?+

The extension supports trusted local desktop VS Code folders on macOS and Linux (glibc), on arm64 and x64. Windows support is coming soon. Native critical-command approval dialogs are currently macOS-only; other platforms retain the denial fallback for those commands. Remote workspaces, WSL, containers, and browser VS Code are not currently supported.
